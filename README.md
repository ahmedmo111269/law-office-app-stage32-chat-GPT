## Stage 21 — Performance & Scalability

**قواعد ملزمة في هذه النسخة:**
- `indexedDB.open()` يظهر في `js/db/db.js` فقط: اتصال قاعدة المكتب واتصال قاعدة اختبار الأداء المنفصلة. لا تُفتح قواعد البيانات في الواجهة.
- الوصول إلى معاملات IndexedDB في وقت التشغيل يمر عبر `js/db/repositories.js`؛ و`getAll()` محصور بها (فحص آلي).
- المبالغ المحفوظة في سجلات المالية والنفقة والتنفيذ والأجور تُخزّن كوحدات صغرى صحيحة (`amountMinor` أو تسمية دلالية مثل `wageMinor` و`totalMinor`). العرض يقسم على 100؛ الحساب النسبي يمكن أن يقرّب مؤقتًا قبل الحفظ.
- تواريخ التقويم كنص ISO `YYYY-MM-DD` في التوقيت المحلي للجهاز؛ الطوابع الزمنية `createdAt`/`updatedAt` هي ISO UTC. لا تحوّل تاريخًا بلا وقت إلى UTC بغرض عرضه.

## تثبيت PWA وتحديثها

يتطلب Service Worker سياقًا آمنًا (HTTPS أو `localhost`)، وتُخزّن وحدات JavaScript وملفات HTML/CSS والأيقونات قبل اعتبار التثبيت صالحًا للعمل دون اتصال. معرّف تثبيت manifest نسبي داخل نطاق المشروع؛ قد يعرض المتصفح إدخال تثبيت جديدًا بدل تثبيت قديم استخدم معرّفًا جذريًا: **أنشئ نسخة مشفرة وتحقق منها قبل إزالة أي تثبيت قديم**. يُسمّى الكاش حسب نطاق تثبيت المشروع وإصدار `3.0.2`، ولا تُمسح كاشات المشاريع الأخرى على المصدر نفسه؛ كاشات الإصدارات التاريخية ذات البادئة العامة لا تُمسح تلقائيًا حفاظًا على المشاريع الأخرى وقد تحتاج مراجعة يدوية عند ضيق الحصة. عند ظهور إشعار إصدار جديد، أعد تحميل الصفحة.

## المزامنة: ما هي بالضبط

- **وضع الدمج (merge):** كل سجل يحمل `uid` عالميًا و`rev` و`updatedAt` و`deviceId`.
  كل تعديل يُسجَّل في `changeLog`، والحذف يُسجَّل كـ `tombstone`.
  عند الدمج يفوز الأحدث حسب `updatedAt`، والتساوي يُحسم بـ `rev` ثم `deviceId`
  (نتيجة حتمية متطابقة على الجهازين). التعارضات تُحفظ في `syncConflicts` للمراجعة.
  تطبيق نفس الحزمة مرتين لا يغيّر شيئًا (idempotent).
- **وضع الحزمة الكاملة (snapshot):** استبدال كامل بعد نسخة طوارئ؛ يُستخدم للتزاوج الأول
  أو بعد استعادة نسخة احتياطية. **ليس** دمجًا.
- **ليست** مزامنة لحظية بين جهازين: لا يوجد خادم. الحزمة ملف مشفّر يُنقل يدويًا؛ تظل بيانات الوصف العامة (النسخة/النوع/معرّف المصدر) ظاهرة خارج النص المشفّر، لا السجلات نفسها.

## التشغيل

```bash
python3 -m http.server 8000
# ثم افتح http://127.0.0.1:8000/
```

الخدمة الأساسية تعمل بدون إنترنت بعد التحميل الأول. ملف النسخة الاحتياطية المشفّرة وكلمة المرور يجب حفظهما خارج الجهاز؛ رمز PIN **قفل للواجهة فقط** ولا يشفّر IndexedDB.

## إعادة تشغيل فحوص الجودة (أدوات تطوير اختيارية)

الملفات تحت `qa/` تُنشئ بيانات اصطناعية في ملفات متصفح تجريبية معزولة، ولا تعبث ببيانات المكتب الحقيقية. التطبيق ذاته لا يحتاج npm ولا Playwright.

```bash
cd qa
npm ci
npx playwright install chromium
# قد يلزم تثبيت مكتبات النظام المطلوبة لـ Chromium على نظام التشغيل.
npm run serve
# في نافذة أو طرفية أخرى داخل qa/:
npm run static
npm run e2e
npm run ui
npm run extras
npm run matrix
npm run legal
npm run search
npm run sync-security
npm run navigation
npm run benchmark-page
npm run benchmark-scale  # Medium وLarge كاملان في قاعدة Benchmark اصطناعية، بملف تعريف تجريبي دائم
npm run nested  # يحاكي مسار GitHub Pages الفرعي ويتحقق من Offline/PWA
npm run load:small
npm run load:medium
PERSISTENT=1 SKIP_INDEX=1 node load.mjs large
```

نتائج هذا الفحص محفوظة في `qa/results/` مع قيودها في `FINAL-REPORT.md`: **Small** على الإصدار 3.0.2 أدخل ١١٬٠٠٠ صف خلال 3.6 ثانية وبنى ٧٤٬٥٤٣ posting خلال 38.3 ثانية؛ **Medium** أدخل ١١٠٬٠٠٠ صف خلال 108.6 ثانية وبنى ٧٤٥٬٩٧٩ posting خلال 560.5 ثانية، وبحث مفهرس دون degraded؛ **Large** أدخل ١٬١٠٠٬٠٠٠ صف خلال 173.5 ثانية في ملف تعريف دائم، واكتمل تقرير جميع السجلات خلال 39.291 ثانية. حجم Large شُغّل بخيار `SKIP_INDEX=1`، لذلك البحث الكامل المفهرس بهذا الحجم **BLOCKED بالحصة / NOT TESTED**، والمسح المتدهور ليس بديلًا عنه. الذاكرة في السجلات heap لاحق للاختبار، وليست ذروة RAM. أداة الصفحة المنفصلة نفسها اجتازت أيضًا Medium (١١٠٬٠٠٠ صف، كتابة 12.534 ثانية) ثم Large (١٬١٠٠٬٠٠٠ صف، كتابة 136.977 ثانية) في ملف تعريف تجريبي واحد؛ تحقق ربط العملاء والقضايا والجلسات، ومُسحت المخازن الاصطناعية الخمسة بعد كل تشغيل، وظل عميل المكتب التجريبي محفوظًا (`qa/results/benchmark-scale.log`). هذه الأداة **لا تبني الفهرس النصي الكامل**، فلا يحل نجاح Large فيها محل بوابة البحث المفهرس للتطبيق. الأداة داخل المتصفح ذات قاعدة بيانات منفصلة لكنها تشارك حصة موقع المكتب؛ لا تشغّل الأحجام الكبيرة على ملف تعريف يحوي بيانات حقيقية. لا تعني محاكاة شاشة 390px اختبار جهاز Android فعليًا، ولا يثبت اختبار سياقين لمتصفح واحد تزامن جهازين ماديين.
