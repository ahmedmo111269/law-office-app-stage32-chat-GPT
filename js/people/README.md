# Stage 3 — People Module

تنفيذ وحدة الأشخاص على قاعدة Stage 1/2 دون تغيير مخطط قاعدة البيانات:
- العملاء.
- الخصوم والأطراف.
- التوكيلات.
- ربط العملاء بالقضايا عبر `caseClients`.
- ملف العميل 360°.

لا توجد بيانات تجريبية، ولا استنتاجات قانونية آلية، ولا تغيير في صحة أو نفاذ التوكيل بناءً على التواريخ.
